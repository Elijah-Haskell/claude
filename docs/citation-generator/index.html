How to use the citation generator

  1. Pick the source type: book, journal article or web page.
  2. Fill in what you know. Leave blank anything the source doesn't have — for example, a web page with no date gets “n.d.” in APA.
  3. Copy the citation. Italics are kept when you paste into Google Docs or Word.

FAQ

Why do I need to fix capitalization myself?
Automatic case changes break proper nouns and acronyms (“NASA”, “Shakespeare”), so the generator keeps your title exactly as typed.
Should I include the DOI?
Yes, when a source has one. Both APA and MLA prefer a DOI over a URL; the generator formats it as https://doi.org/….
Is this always 100% correct?
It follows the published rules for these source types, but instructors sometimes have their own preferences. Check your assignment guidelines, especially for unusual sources.
